# אתר נגיש - תקן ישראלי 5568

אתר זה נבנה בהתאם לתקן הישראלי 5568 לנגישות אתרי אינטרנט, המבוסס על WCAG 2.0 ברמת AA.

## תכונות נגישות

### כפתור נגישות

האתר כולל כפתור נגישות צף הממוקם בצד שמאל של המסך, המאפשר למשתמשים להתאים את האתר לצרכיהם:

#### תכונות זמינות:

1. **התאמת גודל טקסט**
   - הגדלת טקסט
   - הקטנת טקסט
   - איפוס לגודל רגיל

2. **מצבי ניגודיות**
   - ניגודיות רגילה
   - ניגודיות גבוהה (שחור על לבן)
   - מצב כהה (לבן על שחור)

3. **הדגשת קישורים**
   - הדגשת כל הקישורים באתר ברקע צהוב
   - הופך קישורים לבולטים ונראים יותר

4. **פונט קריא**
   - שימוש בפונט Arial עם רווחים מוגדלים
   - מתאים לאנשים עם דיסלקציה

5. **הדגשת כותרות**
   - הדגשת כל הכותרות באתר
   - עוזר לניווט ולהבנת מבנה העמוד

6. **עצירת אנימציות**
   - מבטל כל האנימציות והמעברים
   - מתאים לאנשים רגישים לתנועה

7. **איפוס הכל**
   - מחזיר את כל ההגדרות למצב התחלתי

### תאימות לתקן ישראלי 5568

האתר עומד בדרישות התקן הישראלי 5568 ברמת AA:

#### ✅ תמיכה בעברית
- כיוון RTL (מימין לשמאל)
- תמיכה מלאה בפונטים עבריים
- תוכן בעברית

#### ✅ ניווט מקלדת
- כל התכונות נגישות באמצעות מקלדת
- סדר Tab הגיוני
- אינדיקטורים ברורים למיקוד (Focus)
- תמיכה ב-ESC לסגירת תפריטים

#### ✅ תמיכה בקוראי מסך
- תגיות ARIA נכונות
- תיאורים חלופיים (aria-label)
- הודעות סטטוס לשינויים
- מבנה סמנטי נכון (header, nav, main, footer)

#### ✅ ניגודיות צבעים
- ניגודיות מינימלית של 4.5:1 לטקסט רגיל
- ניגודיות מינימלית של 3:1 לטקסט גדול
- מצב ניגודיות גבוהה זמין

#### ✅ התאמת גודל טקסט
- אפשרות להגדלה עד 200%
- ללא קיטוע תוכן
- שמירה על פונקציונליות

#### ✅ טפסים נגישים
- תיוגים ברורים (Labels)
- הודעות שגיאה מפורטות
- אינדיקציה על שדות חובה

#### ✅ מבנה נכון
- כותרות היררכיות (H1-H6)
- רשימות סמנטיות
- קישורים תיאוריים

#### ✅ שמירת העדפות
- שמירת הגדרות ב-LocalStorage
- טעינה אוטומטית בכניסה מחדש

#### ✅ תאימות לעדפות מערכת
- זיהוי אוטומטי של מצב כהה במערכת
- זיהוי העדפה לאנימציות מופחתות

1. פתח את הקובץ `index.html` בדפדפן
2. לחץ על כפתור הנגישות (איש כחול בצד שמאל)
3. בחר את ההגדרות המתאימות לך
4. ההגדרות יישמרו אוטומטית
